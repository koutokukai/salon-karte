# 【ひろぽん】先行モニター10名 募集オペレーション

作成日：2026-09-04 ／ 目標：**10名を確保し、1ヶ月使ってもらう**

LP：`marketing/lp/index.html`
特典：**個人プラン 生涯無料**（期間限定ではない。正式公開後に料金が変わっても無料のまま）

> **送信は必ず人が行う。** 自動送信ツールは使わない。各プラットフォームの規約に触れる上、
> 個人サロン相手の営業でテンプレ感が出た時点で終わる。1通ずつ、相手の投稿を見てから送る。

---

## 1. 誰に送るか（選定基準）

**満たすもの（3つ以上で送る）**
- 個人でやっている（スタッフの写真が出てこない／「一人サロン」「自宅サロン」の記載）
- **投稿が続いている**（直近1ヶ月に3投稿以上）＝アカウントが生きている
- フォロワー **300〜3,000人**（多すぎると業者扱いされる／少なすぎると開業前）
- 施術写真を自分で撮っている（＝写真が散らばっている確率が高い）
- 予約がDM・LINE中心（＝システムをまだ入れていない）

**送らない**
- 明らかに複数店舗・スタッフ複数
- 予約システムのバナーを出している（既に導入済み）
- 最終投稿が3ヶ月以上前

## 2. 探す場所（貼り付け先・接触先）

### A. Instagram ハッシュタグ（本命）
| 業種 | タグ例 |
|---|---|
| ネイル | #自宅ネイルサロン #プライベートネイルサロン #おうちネイル #ネイリストさんと繋がりたい #駆け出しネイリスト |
| マツエク | #自宅アイラッシュサロン #アイリストさんと繋がりたい #マツエクサロン #まつげパーマサロン |
| ヘア | #フリーランス美容師 #面貸し美容師 #個人サロン美容師 #美容師さんと繋がりたい |
| リラク | #自宅サロン #整体サロン #リラクゼーションサロン #セラピストさんと繋がりたい |

**地域タグを必ず掛ける**（例：#横浜ネイル #札幌マツエク）。地域が入ると返信率が上がる。
「新規オープン」「開業しました」「オープンしました」の投稿は**最優先**。

### B. その他の接触先
| 場所 | 使い方 | 備考 |
|---|---|---|
| **Threads** | LPリンク付きで募集投稿。Instagram と連動して伸びやすい | 一番手軽 |
| **X（旧Twitter）** | #駆け出しネイリスト #開業美容師 等で募集投稿 | 拡散狙い |
| **note** | 「なぜカルテアプリを作ったか」を書いてLPへ導線 | 中長期の資産になる |
| **LINEオープンチャット** | 「サロン開業」「美容師」系のルームで募集 | **宣伝可否をルール確認してから** |
| **Facebookグループ** | サロン経営・開業支援グループ | 同上 |
| **ジモティー** | 地域×無料モニター募集 | 地域密着で拾える |

**注意：どのプラットフォームも、宣伝・募集の可否は自分で規約を確認すること。**
規約違反でアカウントを飛ばすと、営業ルートそのものを失う。

## 3. 送る文面

### ① 初回DM（売り込まない。見てもらう依頼にする）
```
はじめまして。突然のご連絡すみません。
〇〇（地域）の△△（業種）サロンさんの投稿を拝見して、ご連絡しました。

いま、サロンさん向けの「顧客カルテ」だけに絞ったアプリを作っています。
予約管理は入っていません。前回のカラー配合や施術内容を残しておくための、それだけのものです。

10名限定で、1ヶ月無料で使っていただける方を探しています。
使ってくださった方は、その後もずっと無料でお使いいただけます。

売り込みではないので、見るだけでも大丈夫です。
よろしければこちらをご覧ください。
（LPのURL）
```

**書き換える箇所は「地域」「業種」の2つだけ。それ以上いじると量が回らない。**
相手の直近の投稿に1行だけ触れられると返信率が上がる（例：「新規オープンおめでとうございます」）。

### ② 反応があったら（当日中に返す）
```
ありがとうございます！
ご登録用のURLをお送りしますので、こちらから始めてください。
（登録URL）

初回のお客様分だけ、こちらで入力を代行することもできます。
紙のカルテを写真で送っていただければ、こちらで入れておきます。
```
**「入力代行」は必ず出す。** 移行の手間が消えるので、ここで決まる確率が跳ね上がる。

### ③ 1ヶ月後（感想をもらう）
```
1ヶ月ありがとうございました。
使いにくかったところを、1つだけ教えていただけませんか。
「ここが面倒だった」が一番ありがたいです。

お約束どおり、個人プランはこのままずっと無料でお使いいただけます。
```

### ④ フィード・Threads 投稿文
```
サロンの顧客カルテアプリを作りました。10名限定でモニターを募集します。

・前回のカラー配合をすぐ引き出せます
・アプリのインストールは不要、URLを開くだけ
・機種変更してもカルテは消えません
・予約管理は入っていません（今お使いのものと併用してください）

1ヶ月使ってみて、感想を一度だけ聞かせてください。
使ってくださった方は、その後もずっと無料です。

詳細はプロフィールのリンクから。
#自宅ネイルサロン #アイリスト #フリーランス美容師 #自宅サロン
```

## 4. 1日の動き（目安）

| 時間 | 作業 |
|---|---|
| 15分 | タグ＋地域で検索し、**新規10件**をリストに追加 |
| 30分 | 前日リストの10件へDM（1件3分。必ず相手の投稿を見てから） |
| 随時 | 返信対応。**反応があった日のうちに返す**（翌日になると熱が冷める） |

**10名の内訳目標：ネイル3／マツエク3／ヘア2／リラク2。**
1業種に偏ると、次の営業で見せられる実例が偏る。

**返信率の目安：** DM 100通で反応5〜15件、モニター成立2〜5件。
**10名なら 200〜400通が現実的な想定。** 2〜3週間の作業になる。

## 5. 記録する項目（`marketing/outreach-list.csv` を使う）

送信日／プラットフォーム／アカウント／業種／地域／フォロワー数／状態
（未送信・送信済・返信あり・モニター確定・辞退）／次アクション日／メモ

**同じ相手に2回送らない。** これだけは絶対に管理する。無反応への追いは1回まで。

## 6. モニター確定後にやること

1. 登録URLを送る（業種を先に確認しておく。**業種は後から変更できない**）
2. 入力代行を申し出る（紙カルテの写真を送ってもらう）
3. **3日後**に一度だけ「使えていますか」と確認。ここで詰まっている人を拾う
4. 1ヶ月後に感想をもらう → `docs/95-monitor-feedback.md` に集約
5. **本人の許可を取った上で**、次の営業に「同業種の方に作った実例」として使う

## 1. 価格（v3・確定案）

> **この節は 2026-09-04 に全面改訂した。旧案（スタッフ人数で分ける2,980／4,980／9,800円、恒久無料枠）は破棄。**
> 決定の経緯と根拠は `docs/70-target-strategy.md` を参照。

**課金単位は人数ではなくアカウント数。** 人数申告は検証できないが、アカウント数は数えられる。

| プラン | アカウント数 | 月額 |
|---|---|---|
| トライアル | 全プラン共通 | **3ヶ月無料**（クレカ登録なし） |
| 個人 | 1 | **980円** |
| **店舗導入パッケージ** | **3込み** | **2,980円** |
| 追加アカウント | 1つにつき | **+500円** |
| 初期費用 | — | **0円** |

実額：3名 2,980円／5名 3,980円／8名 5,480円／10名 6,480円（10名でも競合オールインを下回る）

**外してはいけない一言：「データはいつでもCSVで持ち出せます」**
競合が訴求している乗り換え不安を、こちらから先に潰す。トライアル終了時も**こちらから**言う。
引き止めない方が残る。

### 乗り換えトーク（個人 → 店舗パッケージ）
個人980円 → 店舗2,980円は3倍のジャンプ。**2人目を雇った瞬間が最大の解約危険地帯。**
「値上げ」ではなく「別物」として売る。

> 「スタッフさんが辞めても、カルテは店に残ります。
> 誰がどの顧客を見たか、持ち出していないかも記録に残ります。
> 店のパソコンから全員分をまとめて確認できます。」

金額の話ではなく**独立リスクの話**として持っていく。ここが店舗パッケージの本体。

## 2. DM文面（テンプレ初案）

営業フローの3番「反応を取る」ためのもの。売り込まず、**見てもらう依頼**にする。

```
はじめまして。○○と申します。
△△（業種）のサロンさん向けに、顧客カルテのアプリを試作しています。

紙のカルテやスマホのメモで、
「前回のカラー配合が分からない」「写真が個人のスマホに散らばる」
といったお困りごとはありませんか？

試作品を見ていただけないでしょうか。
ご意見をいただけたら、それを反映してお渡しします。
（売り込みではないので、見るだけで大丈夫です）
```

**返信が来たら：業種と店名を聞き、翌日までに"その店の名前が入った実物URL"を送る。**
これが今回の営業の全て。文面の巧拙ではなく、**実物の速さ**で勝つ。

## 3. 返信パターン別の対応（半自動化の下地）

| 相手の反応 | 返し |
|---|---|
| 「見てみたい」 | 業種・店名を聞く → 翌日 URL を送る |
| 「いくら？」 | 先に実物を見せてから金額。「まず触ってみてください」 |
| 「今は間に合ってる」 | 「サロンボードは予約ですよね。カルテだけの話です」と棲み分けを明示 |
| 無反応 | 1週間後に1回だけ「同業種の方に作ったものです」と実例を送る。それ以上は追わない |

## 4. 仕組み化（Phase 3 で着手）

- Instagram のハッシュタグ・地域タグからのリスト化（業種×エリアで管理）
- 送信履歴と反応の記録（誰にいつ送ったか、次アクションはいつか）
- **完成アプリのストック**を業種別に並べ、次の営業の「実例」として即座に出せる状態にする

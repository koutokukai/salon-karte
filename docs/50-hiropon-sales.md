# 【ひろぽん】営業設計 メモ（Phase 3 の準備）

作成日：2026-09-04 ／ 提出先：ユーザー（営業提案）／ ゲンさん（進捗）

> Phase 3 が本番だが、**プロダクトが出来上がる前に決めておくべきこと**だけ先に置く。
> 金額と方針はユーザー判断。ここに書くのは案。

## 1. 価格案（リチャードの競合調査を踏まえる）

競合は月額 390円〜1,000円（単機能）／9,800円前後（オールイン）。
我々は**単機能側の上、オールインの下**に置くのが取りやすい。

| プラン | 想定 | 月額（案） | 根拠 |
|---|---|---|---|
| ソロ | 個人サロン（スタッフ1名） | **2,980円** | 競合の単機能より高いが「業種専用＋実物提示」で正当化できる |
| スタンダード | スタッフ2〜4名 | **4,980円** | 主力。ここに寄せる |
| 店舗 | スタッフ5名以上 | **9,800円** | オールインと同額。ここは無理に取りに行かない |
| 初期費用 | — | **0円** | 導入ハードルを一切作らない。ここは絶対に取らない |

**外してはいけない一言：「データはいつでもCSVで持ち出せます」**
競合が訴求している乗り換え不安を、こちらから先に潰す。

## 2. DM文面（テンプレ初案）

営業フローの3番「反応を取る」ためのもの。売り込まず、**見てもらう依頼**にする。

```
はじめまして。○○と申します。
△△（業種）のサロンさん向けに、顧客カルテのアプリを試作しています。

紙のカルテやスマホのメモで、
「前回のカラー配合が分からない」「写真が個人のスマホに散らばる」
といったお困りごとはありませんか？

試作品を見ていただけないでしょうか。
ご意見をいただけたら、それを反映してお渡しします。
（売り込みではないので、見るだけで大丈夫です）
```

**返信が来たら：業種と店名を聞き、翌日までに"その店の名前が入った実物URL"を送る。**
これが今回の営業の全て。文面の巧拙ではなく、**実物の速さ**で勝つ。

## 3. 返信パターン別の対応（半自動化の下地）

| 相手の反応 | 返し |
|---|---|
| 「見てみたい」 | 業種・店名を聞く → 翌日 URL を送る |
| 「いくら？」 | 先に実物を見せてから金額。「まず触ってみてください」 |
| 「今は間に合ってる」 | 「サロンボードは予約ですよね。カルテだけの話です」と棲み分けを明示 |
| 無反応 | 1週間後に1回だけ「同業種の方に作ったものです」と実例を送る。それ以上は追わない |

## 4. 仕組み化（Phase 3 で着手）

- Instagram のハッシュタグ・地域タグからのリスト化（業種×エリアで管理）
- 送信履歴と反応の記録（誰にいつ送ったか、次アクションはいつか）
- **完成アプリのストック**を業種別に並べ、次の営業の「実例」として即座に出せる状態にする

## 5. ひろぽんからユーザーへ

**プロダクト側に1つだけお願いがある。**
デモ用に「店名だけ差し替えた URL」を最短で用意できる状態にしておいてほしい。
営業の勝負どころは**反応があってから実物を送るまでの時間**で、そこが1日を超えると熱が冷める。

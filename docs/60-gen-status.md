# 判断記録 第2回（2026-09-04・戦略の見直し）

ユーザーからの指摘により、**ターゲット・価格・プラン構成を全面的に見直した。**
確定内容は `docs/70-target-strategy.md`、実装設計は `docs/80-edison-staff-design.md`。

## ユーザー指摘と、それによる方針変更

| ユーザー指摘 | 変更前 | 変更後 |
|---|---|---|
| 4業種とも**個人サロン**を押さえたい。店舗は独自カルテを持っており移行しない | 店舗規模で3段階 | **駆け出し・自宅サロン・1店舗個人事業主が主戦場**。大型店は狙わない |
| **紙カルテ相手でも「多少便利」では勝てない。人間は変化を拒む** | 機能の充実で訴求 | **移行コストをゼロに近づける設計**へ転換（紙を撮って貼るだけ／二重運用を許す／入力代行） |
| 恒久無料プランではなく**期間限定にすべき**。3ヶ月無料 | 顧客30人まで無料 | **3ヶ月無料に統一。無料プランは廃止** |
| 1ヶ月で十分か？ | — | **不十分と回答。ヘアは1ヶ月で0回転** → 3ヶ月で確定 |
| **Webアプリの強みを全面に押し出す** | 特に訴求せず | 「機種変更してもカルテは消えません」を営業の一言目に |
| **店舗プランは必要**。スタッフ独立で客が離脱する | 店舗プラン廃止案 | **復活。ただし売りは便利さではなく顧客資産の防衛** |
| 課金は**アカウント数**の方がよいか | 人数ベース | **アカウント数課金に変更**（検証可能・自動増収・説明が1行） |
| ①誰がどう触ったか ②ログ ③店のPCで一括管理 | 未設計 | **`staffs` ＋ `audit_logs` ＋ オーナー用PC画面を設計**（docs/80） |

## ゲンさんの判断

| 論点 | 判断 | 理由 |
|---|---|---|
| 恒久無料プランの廃止 | **採用** | 期間限定の方が移行率が上がるという指摘が正しい。無料枠競争に付き合う必要もない |
| トライアル1ヶ月 | **却下（3ヶ月を採用）** | 施術周期の計算上、1ヶ月ではヘアが0回転。**核心価値が発動する前に判断されてしまう** |
| クレカ登録を求めない | **採用** | 開始率が落ちる。トライアルの目的は蓄積であって課金導線ではない |
| 店舗ごとのコード改造 | **却下** | 10店舗で保守が破綻する。**設定（独自項目・表示切替・プリセット）で9割吸収**する |
| ボタン配置の店別カスタム | **却下** | サレオツの設計思想の根幹。押す位置が変わると誤操作が増える。現場の安全を優先 |
| 店舗プランの復活 | **採用** | 「人に客がつく」は経営者の恐怖であり、機能ではなく**リスク商品**として売れる |
| アカウント数課金 | **採用** | 人数申告は検証不能。アカウント数は実測でき、増員時に自動で増収する |
| 個別カルテの閲覧ログ | **却下** | 件数が膨大になり本命のログが埋もれる。**大量閲覧とエクスポートの2点に絞る** |
| スタッフの閲覧範囲を既定で制限 | **却下（既定は全件・記録あり）** | 担当交代・ヘルプが日常。見えないと業務が回らない。制限は任意設定にする |
| スタッフ管理の実装時期 | **デプロイ前を推奨** | 本番データ投入後だと移行が発生する。今なら移行コストゼロ |

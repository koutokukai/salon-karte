# 【ひろぽん】DM実務playbook — 今日から手を動かす手順書

作成日：2026-09-04 ／ 対象：Instagram `@karte_lab` からのモニター10名募集
前提文書：`docs/70-target-strategy.md`（価格・確定事項）／`docs/90-monitor-campaign.md`（オペ全体）
記録先：`marketing/outreach-list.csv`

> **この文書は「探す→選ぶ→送る→返す→数える」の実務だけを書く。**
> 戦略の議論はしない。迷ったら docs/70 と docs/90 が上位。

**動かしてはいけない確定事項（文面に書く数字はこれだけ）**
- 個人プラン **月980円** ／ 店舗導入パッケージ **月2,980円**（2アカウント込み・追加1つ +500円）
- 通常トライアル **3ヶ月無料**（クレカ登録なし）
- **モニター特典：10名限定・1ヶ月使ってもらう・その方は個人プラン生涯無料**
- 初期費用 0円 ／ データはいつでもCSVで持ち出せる

**送信は必ず人が手で送る。** 自動送信ツールは使わない。1通ずつ、相手の投稿を見てから送る。

## 0. 送る前に用意するもの（初日15分だけ）

| # | 準備 | 状態 |
|---|---|---|
| 1 | LP公開URL（本文中の `{{LP_URL}}` に差し込む文字列） | **別作業で用意中。届いたら本書の `{{LP_URL}}` を一括置換して確定版にする** |

| 3 | フィード投稿を3本（docs/90 の④の投稿文でよい） | **DMを受けた人は必ずプロフを見る。投稿ゼロは業者判定される** |
| 4 | `marketing/outreach-list.csv` をスプレッドシートで開いておく | 二重送信の防止はここでしかできない |

> **1〜3が揃うまで大量送信を始めない。** 空アカウントからのDMは返信率がほぼゼロで、送った分だけ在庫が減る。

## 1. 送信先の探し方（Instagram）

### 1-1. 検索窓にそのまま打てる文字列

**業種タグ（本命）**

| 業種 | 打つ文字列 |
|---|---|
| ネイル | `#自宅ネイルサロン` `#プライベートネイルサロン` `#おうちネイル` `#ネイリストさんと繋がりたい` `#駆け出しネイリスト` `#マンションネイルサロン` |
| マツエク・アイ | `#自宅アイラッシュサロン` `#アイリストさんと繋がりたい` `#マツエクサロン` `#まつげパーマサロン` `#プライベートサロンアイラッシュ` |
| ヘア | `#フリーランス美容師` `#面貸し美容師` `#個人サロン美容師` `#美容師さんと繋がりたい` `#シェアサロン美容師` |
| リラク・整体 | `#自宅サロン` `#整体サロン` `#リラクゼーションサロン` `#セラピストさんと繋がりたい` `#おうちサロン` |

**開業直後タグ（最優先。ここが一番決まる）**

`#新規オープンサロン` `#サロン開業` `#開業しました` `#プレオープン` `#独立しました` `#駆け出しサロン`

**地域を必ず掛ける**（返信率がはっきり上がる）

`#横浜ネイル` `#札幌マツエク` `#福岡美容師` `#名古屋自宅サロン` `#仙台まつげパーマ` `#神戸リラクゼーション`
→ 型は **「地域名＋業種」**。自分が土地勘のある地域から始めると、1行目のひと言が書きやすい。

### 1-2. 掘り方の手順

1. タグを開き、**「最近の投稿」タブ**を見る（人気投稿は上位アカウント＝大型店が多く、ハズレ）
2. 投稿を上から順に開き、アカウントに飛ぶ
3. §2 のチェックリストで判定 → `◯` ならCSVに1行追加（**この時点ではまだ送らない**）
4. タグ1本で10〜15件見て、`◯` が3件も出なければタグを替える

**所要時間の目安：1件あたり60〜90秒。**（プロフィール15秒 → 直近投稿9枚をざっと20秒 → 固定投稿とハイライト20秒 → CSV記入15秒）
**リスト10件＝15分**が標準。ここが20分を超えているならタグ選びが悪い。

### 1-3. 探す＋送るを同じ時間にやらない

**リスト作りは前日分、送信は今日分**にずらす。同じ画面で「見つけた→即DM」をやると、
判定が甘くなり、Instagram 側からも短時間の連続アクションに見える。

## 2. 送る／送らない の判定チェックリスト

**◯（送る）：以下の8項目のうち5つ以上に✓が付いたら送る**

- [ ] フォロワー **300〜3,000人**（下限未満は開業前、上限超は業者DMが飽和していて開かない）
- [ ] 直近1ヶ月に **3投稿以上**（アカウントが生きている）
- [ ] 最終投稿が **1ヶ月以内**
- [ ] プロフか投稿に **「一人サロン」「自宅サロン」「プライベートサロン」「完全予約制」「マンションの一室」** 等の個人運営を示す語がある
- [ ] **施術写真を自分で撮っている**（素材画像・引用の寄せ集めではない）＝写真がスマホに散らばっている
- [ ] 予約導線が **DM・LINE公式** 中心（プロフに「ご予約はDMまたはLINEから」）＝まだ何も入れていない
- [ ] スタッフの写真・名前が出てこない（出てきても2名まで）
- [ ] **開業1年以内の気配**（「オープンしました」「独立しました」の固定投稿、投稿総数が100件未満）

**✕（送らない）：1つでも当たったら送らない。CSVの判定を `✕` にして理由をメモ**

- [ ] 複数店舗・スタッフ3名以上（求人投稿を出している店はほぼこれ）
- [ ] プロフに **予約サイトのリンク**（ホットペッパー／サロンボード等）が貼ってある＝既に基幹システムが入っている
- [ ] プロフに顧客管理・カルテ系サービスのバナーやリンクがある＝導入済み
- [ ] 最終投稿が **3ヶ月以上前**
- [ ] **法人臭**：会社概要リンク、`〜株式会社`、代表挨拶、スクール事業、フランチャイズ本部、採用ページ
- [ ] **同業・競合**：サロン向けツール、集客コンサル、SNS運用代行、サロン開業スクール
- [ ] 商材販売・アフィリエイト色が強い（物販アカウント）
- [ ] DM受付をしていない／プロフに「DMでの営業はお断り」と明記

**△（保留）：判定を `△` にして送らない。** 迷った時間そのものが在庫の無駄。
1日の最後に `△` をまとめて見返し、その日の残り枠があれば`◯`に上げる。

**業種の配分目標：ネイル3／マツエク3／ヘア2／リラク2。**
1業種に偏ると、次の営業で見せられる実例が偏る。リスト時点でこの比率を意識する。

## 3. DM文面（`{{LP_URL}}` に公開URLを差し込む）

> **`{{LP_URL}}` はそのまま貼らない。** LP公開URLが確定したら、この節の `{{LP_URL}}` を実URLに置換して確定版にする。
> 書き換えてよいのは **【地域】【業種】【ひと言】** の3ヶ所だけ。それ以上いじると1日の量が回らない。

### ① 初回DM（1通目・短く。スマホで3スクロールしない長さ）

**URLは1通目の末尾に1本だけ。** 冒頭や中盤にURLがあると、開いた瞬間に広告と判定されて閉じられる。

```
はじめまして、突然のご連絡すみません。
【地域】の【業種】サロンさんを探していて、投稿を拝見しました。
【ひと言：例）新規オープンおめでとうございます／お写真がきれいで手が止まりました】

いま、サロンさん向けに「顧客カルテ」だけのアプリを作っています。
前回の施術内容や写真を残しておくための、それだけのものです。

10名限定で、1ヶ月使ってくださる方を探しています。
使ってくださった方は、その後もずっと無料でお使いいただけます。

売り込みではないので、見るだけでも大丈夫です。
{{LP_URL}}
```

- **【ひと言】は必ず埋める。** ここが空だとテンプレだと分かる。相手の直近投稿から15秒で拾う
- 金額はここでは出さない。「1ヶ月使う→その後ずっと無料」だけ
- 自分の名前を名乗らないほうが短く収まる。聞かれたら答える

### ①-b URLを貼らない版（アカウントが若い最初の3日はこちらを使う）

新しいアカウントからURL付きDMを連投すると制限がかかりやすい。**最初の30通ほどはこの版を使う。**

```
はじめまして、突然のご連絡すみません。
【地域】の【業種】サロンさんの投稿を拝見しました。
【ひと言】

いま、サロンさん向けに「顧客カルテ」だけのアプリを作っていて、
10名限定で1ヶ月使ってくださる方を探しています。
使ってくださった方は、その後もずっと無料です。

ご興味あればページのリンクをお送りします。
（売り込みではないので、見るだけでも大丈夫です）
```
→ 「見たいです」と返ってきたら §3-④-C の返しで `{{LP_URL}}` を送る。**返信の中のURLは制限を受けにくい。**

### ② フォロー1通（既読スルー・無反応向け・**1回だけ**）

**送信から7日後**に送る。それ以上は絶対に追わない。追うと通報リスクが跳ね上がる。

```
先日は突然のご連絡すみませんでした。
その後、同じ【業種】のサロンさんにも使っていただいていて、
「前回の内容をすぐ出せるのが助かる」と言っていただけました。

モニター枠は残り【N】名です。もし合わなければこのままで大丈夫です、
最後に一度だけお知らせでした。
{{LP_URL}}
```

- 実例がまだ無い段階では2〜3行目を **「作っている画面をそのままお見せできます。1分で見終わります。」** に差し替える
- **嘘の実例は書かない。** 1件でも確定してから使う
- 「残り【N】名」は実数を書く。盛らない

### ③ ステータス管理の値（`marketing/outreach-list.csv` の `ステータス` 列）

| 値 | 意味 | 次にやること |
|---|---|---|
| `未着手` | リストに入れただけ。まだ送っていない | 翌日の送信枠で送る |
| `送信済` | 1通目を送った | 7日後にフォロー1通 |
| `追い送信済` | フォロー1通も送った | **これ以上追わない。**放置 |
| `返信あり` | 何らかの返信が来た | **その日のうちに**返す（§3-④） |
| `検討中` | 「考えます」「後で見ます」で止まっている | 5日後に一度だけ「いかがでしたか」 |
| `確定` | モニター参加が決まった | 登録URL送付 → 3日後に様子確認 → 1ヶ月後に感想 |
| `辞退` | 断られた | 追わない。**礼だけ返して終える**（悪評が一番高くつく） |
| `対象外` | 判定 `✕`／送信後に法人・導入済みと判明 | 触らない |
| `不達` | DMが届かない・アカウント削除・ブロック | 触らない |

**同じ相手に2回送らない。これだけは絶対に守る。** 送信前に必ずCSVを `handle` で検索する。

### ③-b CSVの列の書き方（`marketing/outreach-list.csv`）

| 列 | 書く値 |
|---|---|
| `no` | 連番。振り直さない |
| `handle` | `@` から書く（例 `@example_nail_01`）。**送信前にこの列を検索して二重送信を防ぐ** |
| `url` | プロフィールURL |
| `業種` | `ネイル` / `マツエク` / `ヘア` / `リラク` の4つだけ |
| `フォロワー数` | 数字のみ（例 `820`） |
| `判定` | `◯`（送る） / `△`（保留） / `✕`（送らない） — §2 の基準 |
| `送信日` | `YYYY-MM-DD`。1通目を送った日 |
| `テンプレ` | `初回` / `初回b`（URLなし版） / `フォロー` / `返しA`（料金） / `返しB`（他アプリ） / `返しC`（見たい） |
| `返信` | 空 / `あり` / `なし`（7日経過して無反応） |
| `ステータス` | §3-③ の9値のみ |
| `メモ` | 地域・ひと言に使った内容・次アクション日を1行で。**カンマは使わない**（`/` で区切る） |

### ④ 返信が来たときの返し（当日中に返す。翌日になると熱が冷める）

#### A. 「いくらですか？」と料金を聞かれた

**値段から逃げない。即答する。ごまかすと一番信用を失う。**

```
ありがとうございます、先に金額をお伝えしますね。

モニターの10名の方は、1ヶ月使っていただいたあと、
個人プランをその後もずっと無料でお使いいただけます。正式公開後に料金が変わっても無料のままです。

通常の料金は、おひとりでお使いの個人プランが月980円です。
（スタッフさんとアカウントを分けて使う店舗向けは月2,980円／2アカウント込みです）
どなたでも最初の3ヶ月は無料で、クレジットカードの登録もありません。

初期費用はかかりません。データはいつでもCSVで全部お持ち出しいただけます。
まずは触ってみてください。
{{LP_URL}}
```

- **モニター枠が残っていれば必ず先に出す。** 980円の話から入ると比較検討モードに入る
- 「持ち出せます」は毎回言う。乗り換え不安をこちらから先に潰す

#### B. 「他のアプリを使っています」と言われた

**否定しない・比較しない・乗り換えを迫らない。併用でいいと即座に言い切る。**

```
ありがとうございます、すでにお使いなんですね。失礼しました。

うちはカルテだけに絞っていて、今お使いのものと置き換えるものではないんです。
そのままお使いいただきながら、カルテのところだけ試していただく形で大丈夫です。

もし今のもので足りていれば、無理に増やす必要はまったくないです。
ひとつだけ、機種変更してもデータが消えないのと、
スマホでもPCでもタブレットでも同じ画面が出せる、というのが違うところです。

お手すきのときにでも見ていただければ。
{{LP_URL}}
```

- ここで粘らない。粘った瞬間に営業になる。**「無理に増やす必要はない」は必ず入れる**
- 相手が具体的なサービス名を出しても、その名前を出して比較しない

#### C. 「とりあえず見てみたいです」と言われた

**一番決まりやすい。ここで質問を増やさない。URLを出す→業種だけ聞く、の2手で終える。**

```
ありがとうございます！こちらです。
{{LP_URL}}

インストールは不要で、開いたらそのまま使えます。

ひとつだけ先に伺えたら助かります。
ネイル・マツエク・ヘア・リラクのどちらでしょうか？
（最初に選んでいただく項目があり、あとから変更できないので先に合わせておきます）

それと、いまお使いの紙のカルテがあれば、
写真を送っていただければ初回のお客様分はこちらで入力しておきます。
お手を動かしていただかなくて大丈夫です。
```

- **入力代行は必ず出す。** 移行の手間が消えるので、ここで決まる確率が跳ね上がる
- 業種は登録後に変更できない。**URLを送る前に必ず確認する**
- 質問は「業種」1つだけ。店名・人数・場所を一度に聞かない（フォームに見えた時点で止まる）

## 4. Instagram の安全な送り方（凍結させない）

営業ルートそのものを失うのが最大の損失。**枠を使い切ることより、アカウントを生かすことを優先する。**

### 1日あたりの本数

| アカウントの状態 | 1日の送信上限 | 備考 |
|---|---|---|
| 開設・稼働まもない最初の3日 | **10〜15通** | §3-①-b のURLなし版のみ |
| 4〜7日目 | **20通** | URLありに切り替えてよい |
| 安定後（2週目〜） | **25〜30通** | **これ以上は増やさない** |

**判断の基準は「1日◯通まで大丈夫」ではなく、アカウントの年齢と挙動の自然さ。**
実際の制限値は公表されておらず変動する。上表は安全側に振った運用値。

### 守ること

1. **一定間隔を空ける。** 連続で送らない。**1通ごとに2〜4分**（相手の投稿を見てから書けば自然にこの間隔になる）
2. **一気に送らない。** 午前10通・午後10通のように**2〜3回に分ける**
3. **完全に同じ本文を連投しない。** 【地域】【業種】【ひと言】が毎回変わっていれば良い。**特に【ひと言】は必ず変える**
4. **1通目にいきなりURLを貼らない**（最初の30通、および相手が明らかに警戒しそうなアカウントの場合）。URLは**文末に1本だけ**
5. **短縮URLを使わない。** `bit.ly` 等はスパム判定されやすい。LPのURLをそのまま貼る
6. **DMの前に1アクション。** 直近投稿に「いいね」を1つ（コメントはしない）。無言DMより開封される
7. **フォローとDMを同時にしない。** フォローするなら前日に済ませる
8. **返信が来ている相手への返信を優先。** 返信のやり取りがあるアカウントは健全と判定されやすい
9. **PCブラウザ版とスマホアプリを短時間で行き来しない。** 送信は**スマホアプリに統一**する
10. **警告・送信失敗が出たら、その日は即座に止める。** 翌日は半分の本数から再開
11. **ブロック・通報が続いたら文面を疑う。** 追い送信をやめ、初回文面を短くする

### 止める合図（1つでも出たら当日は終了）

- 「アクションがブロックされました」の表示
- DMが送れない／送信直後に消える
- 返信が急にゼロになる（既読すら付かない）

## 5. 1日の型（30〜60分で回るサイズ）

**新規リスト10件＋送信10通が1日の標準。** これを20日続けて約200通、ここが最低ライン。

| 時間 | 所要 | やること |
|---|---|---|
| 朝（9:30頃） | 10分 | **返信チェック最優先。**来ていたら §3-④ で即返す |
| 朝（9:40頃） | 15分 | タグ＋地域で検索し、**新規10件**をCSVに追加（`未着手`）。※送るのは翌日分 |
| 昼（12:30頃） | 15分 | 前日リストの **5通**を送信（1通2〜4分）。CSVに `送信日` `テンプレ` を記入 |
| 夕（18:00頃） | 15分 | 残り **5通**を送信。※**18〜21時が最も開封される時間帯** |
| 夜（21:00頃） | 5分 | 返信の最終チェック → 当日中に返す。7日前の `送信済` にフォロー1通 |

**合計 約60分。**時間が取れない日は「**返信対応 → 送信 → リスト作り**」の順に削る。
**返信を放置するのが唯一の致命傷。**リスト作りは1日飛ばしても取り返せる。

**週次（金曜・10分）**
- CSVを集計し §6 の数字を出す
- 返信のあった文面／なかった文面を見比べ、初回DMの【ひと言】の当て方を1点だけ直す
- 業種の偏りを確認し、翌週のタグを寄せる

## 6. 進捗の数え方

### 目標からの逆算（docs/90 の想定：10名確定に200〜400通）

| 指標 | 計算 | 目安 |
|---|---|---|
| **送信数** | — | 10名確定まで **200〜400通** |
| **返信率** | 返信あり ÷ 送信数 | **5〜15%**（100通で5〜15件） |
| **確定率（対送信）** | 確定 ÷ 送信数 | **2〜5%**（100通で2〜5名） |
| **確定率（対返信）** | 確定 ÷ 返信あり | **30〜40%**（返信さえ来れば3人に1人） |
| **1日の送信** | — | **10通**（最大30通） |
| **到達までの期間** | 200〜400通 ÷ 10通/日 | **20〜40日**（1日20通なら10〜20日） |

### 週ごとのチェックポイント

| 時点 | 累計送信 | 期待される確定数 | 下回っていたら |
|---|---|---|---|
| 1週目末 | 50〜70通 | 1〜3名 | まだ判断しない。**送信数だけ確認**する |
| 2週目末 | 100〜140通 | 3〜6名 | **返信率**を見る（下記） |
| 3週目末 | 150〜210通 | 5〜8名 | 同上 |
| 4週目末 | 200〜280通 | **8〜10名** | 送信本数を1日20通へ引き上げ |

### 数字が悪いときの切り分け（順番を守る）

1. **返信率が5%未満** → 問題は**送信先の選定**。文面をいじる前にタグを替える。
   特に「開業直後タグ」と「地域タグ」の掛け合わせが効いていない可能性が高い
2. **返信率は10%あるのに確定率が20%未満** → 問題は**返信後の返し**。
   §3-④ で質問を増やしすぎていないか、入力代行を出し忘れていないかを確認
3. **返信も確定も出ているが数が伸びない** → 単に**送信数不足**。1日の本数を上げる（上限30通）

### 毎日CSVに残す3つの数字

`本日の送信数` ／ `本日の返信数` ／ `累計確定数`
週次の集計はCSVの `ステータス` 列を数えれば出る。**別の管理表は作らない。**

## 7. 確定後の流れ（`ステータス` = `確定` になったら）

1. **登録URLを送る。**送る前に**業種を確認**（登録時に1度だけ選択、あとから変更できない）
2. **入力代行を申し出る**（紙カルテの写真を送ってもらう）
3. **3日後**に一度だけ「使えていますか」。詰まっている人をここで拾う
4. **1ヶ月後**に感想をもらう → `docs/95-monitor-feedback.md` に集約
5. **本人の許可を取った上で**、次の営業に「同業種の方に作った実例」として使う（無断使用は絶対にしない）

**約束したことは必ず守る。** 「その日か翌日には直します」と言った以上、直せない要望は最初から言わない。
モニター10名は最初の顧客であり、最初の紹介元でもある。

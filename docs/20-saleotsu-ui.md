# 【サレオツ】業種別 UI ワイヤー 初案

提出日：2026-09-04 ／ 提出先：ゲンさん

## 設計思想（華やかさは捨てる）

このアプリを使うのは、**施術中に片手で、濡れた手で、急いで触るスタッフ**である。
つまり敵は「見た目の地味さ」ではなく、**誤タップ・迷い・入力の面倒くささ**の3つ。

### 5つの原則

1. **親指ゾーン優先** — 主要アクション（保存・新規カルテ）は必ず**画面下部**に固定する。
   上部に置いたボタンは片手で押せず、持ち替えの瞬間にスマホを落とす。
2. **タップ領域 最低 48px（推奨 56px）** — 削除系だけは意図的に**小さく・端に**置く。
   誤操作コストが非対称なものは、押しやすさも非対称にする。
3. **1画面1目的** — カルテ入力を1ページに全部並べない。「基本 → 業種別 → 写真 → メモ」で区切る。
   長いフォームは離脱ではなく**"後で入力しよう"**を生み、それが運用崩壊の始まり。
4. **危険情報は色より先に位置** — アレルギー・禁忌は顧客詳細の**最上部**に赤帯で常駐。
   色覚特性を考慮し、色だけに頼らず **⚠ アイコン＋テキスト**を併記する。
5. **入力より選択** — 自由記述は最後の手段。カール種別・圧レベル等は**チップ選択**にする。
   前回値を初期表示し、「前回と同じ」ボタンを置く。これが継続利用率を決める。

## 配色（業種別テーマ）

彩度は抑える。**長時間見ても疲れない**ことが最優先。背景は常に白/オフホワイト。

| 業種 | メインカラー | 用途 | 心理的意図 |
|---|---|---|---|
| ネイル | 紫 `#7C5CBF` | ヘッダー・主要ボタン | 創造性・華やかさの記号。ネイリストの自己認識に合う |
| マツエク | ローズ `#C4728A` | 同上 | 目元・繊細さ。強すぎない赤で"やわらかい緊張感" |
| ヘア | ブラウン `#8A6A4F` | 同上 | 落ち着き・信頼。美容室の内装と衝突しない |
| リラク | セージ `#5E8C6A` | 同上 | 鎮静・回復。医療的すぎない緑 |

**全業種共通の固定色（テーマで変えない）**
- 危険/アレルギー：`#D64545`（赤）— 業種で変わると事故る
- 保存/成功：`#2E7D5B`（緑）
- テキスト：`#1F2328` ／ 補助テキスト：`#6B7280` ／ 罫線：`#E5E7EB`

## 画面ワイヤー

### 1. ログイン
```
┌─────────────────┐
│                 │
│   サロンカルテ    │   ← ロゴのみ。装飾なし
│                 │
│  ┌───────────┐  │
│  │ メールアドレス │  │   高さ 56px
│  └───────────┘  │
│  ┌───────────┐  │
│  │ パスワード    │  │
│  └───────────┘  │
│  ┌───────────┐  │
│  │   ログイン   │  │   ← 業種テーマ色・高さ 56px
│  └───────────┘  │
└─────────────────┘
```

### 2. ダッシュボード
```
┌─────────────────────────┐
│ ● ○○ネイル       [設定]  │  ← ヘッダー：業種テーマ色の細帯のみ
├─────────────────────────┤
│  顧客 128名 / 今月のカルテ 42件 │  ← 数字は大きく。承認欲求＝継続動機
├─────────────────────────┤
│ 最近来店した顧客              │
│ ┌─────────────────────┐ │
│ │ 山田 花子    3日前   ›│ │  ← 行高 64px。名前は太字18px
│ │ ⚠ アレルギーあり       │ │  ← 該当者のみ赤テキスト
│ ├─────────────────────┤ │
│ │ 鈴木 美咲    5日前   ›│ │
│ └─────────────────────┘ │
├─────────────────────────┤
│ [顧客一覧]    [＋新規カルテ] │  ← 下部固定。右が主アクション
└─────────────────────────┘
```

### 3. 顧客詳細（最重要画面）
```
┌─────────────────────────┐
│ ‹ 戻る    山田 花子        │
├─────────────────────────┤
│ ⚠ アレルギー：ラテックス     │  ← 赤帯。該当時のみ。最上部固定
├─────────────────────────┤
│ 誕生日 4/12 ／ 犬（ポチ）    │  ← 会話ネタを常時1行で表示
│ 好き：あんぱん / 逃げ恥       │  ← ★ 差別化の核。折りたたまない
├─────────────────────────┤
│ [カルテ履歴] [プロフィール] [チャット] │ ← タブ
├─────────────────────────┤
│ 2026/08/20  担当:佐藤       │
│ ┌────┬────┐              │
│ │before│after│  カラー:P-12 │  ← サムネ 80px 角丸
│ └────┴────┘              │
├─────────────────────────┤
│ [前回をコピーして新規カルテ]   │  ← ★ リチャード提案を採用
└─────────────────────────┘
```

### 4. 新規カルテ入力（業種別分岐）
```
共通ヘッダ（来店日・担当スタッフ・メニュー）
        ↓
┌── 業種別ブロック ──────────┐
│ ネイル : カラー配合 / 形 / 長さ  │
│ マツエク: カール[J][B][C][D]  │  ← チップ選択
│          本数 / 太さ / 長さ    │
│ ヘア   : カラー配合 / パーマ /  │
│          トリートメント / 長さ  │
│ リラク : 圧[弱][中][強] / 部位 │
│          オイル / 主訴 / 禁忌  │
└──────────────────────────┘
        ↓
写真（before / after）→ メモ → [保存]（下部固定・56px）
```

**業種で変わるのは "中央ブロックと色" だけ。外枠は完全に同一。**
これによりスタッフが機種変・店舗異動しても迷わず、我々は保守コストを最小化できる。

# 【リチャード】業種別カルテアプリ調査 — 第1次報告

調査日：2026-09-04 ／ 提出先：ゲンさん

## 1. 市場の要点（結論から）

- **予約系（サロンボード / ホットペッパー連動）は完全に根付いている。ここは触らない判断で正しい。**
- 一方、カルテ専用のプレイヤーは「安い・軽い・単機能」で成立している。
  価格帯は **月額 390円〜1,000円**（個人向け）／**9,800円前後**（店舗向けオールインワン）。
  → **我々の価格設計は「サロンボードの下」に置ける。ここが勝ち筋。**
- 無料枠（顧客80人まで無料など）が競合の標準的な入口。**我々は「もう動く実物を見せる」で入口を作るので、無料枠競争に付き合う必要はない。**

## 2. 主要プレイヤー（横断 TOP5）

| ツール | 立ち位置 | 学ぶべき点 |
|---|---|---|
| **LiME** | 美容師が設計。スマホ操作特化、カルテ＋予約 | 「現場の動線」への執着。片手・施術中の操作を前提にした設計 |
| **Bionly** | 顧客満足度アップをコンセプトにした顧客管理＋電子カルテ | カルテを「接客の武器」として位置づける訴求。我々の"リピート率アップ"と同軸 |
| **salon record** | カルテのみに絞り月額950円固定 | **単機能・定額・データ持ち出し自由**。解約時の不安を消す訴求が強い |
| **カルテナ** | 顧客80人まで無料、月額390円〜。ネイル/美容室別のLPを持つ | **業種別にLPを出し分ける**手法。我々の業種別分岐と相性が良い |
| **EyeRec** | アイリスト専用（マツエク・マツパ・眉） | 業種特化の深さ。カール/太さ/本数/長さを**上下左右で**記録する粒度 |

（参考：Karute Kun、からだケア〈整体・リラク向け〉、Aiony 等）

## 3. 業種別・必須カラム提案（→ ゲンさんへ上申）

現仕様のカラムはおおむね妥当。**以下は追加を推奨する差分のみ**を挙げる。

### 共通（全業種）
| 提案カラム | 理由 | 優先度 |
|---|---|---|
| `menu_name`（施術メニュー名） | 競合の共通項目に必ず入る。履歴一覧の見出しになる | **高** |
| `price`（金額） | 単価・平均単価の把握＝リピート施策の根拠になる | **高** |
| `next_visit_guide`（次回来店目安：日数） | リピート率アップの本丸。「3週間後」を記録できると後の LINE 配信に直結 | **高** |
| `counseling_note`（カウンセリング/要望） | 施術メモと要望は別物。混ぜると検索性が落ちる | 中 |

### ネイル
- `nail_shape`（形：ラウンド/スクエア/オーバル等）、`nail_length`（長さ）、`nail_off_type`（オフ有無・種別）
- `nail_color_formula` は既存で正しい。**色ムラ問題の解決＝配合メモが刺さる核心**

### マツエク
- `eyelash_curl_type` / `eyelash_count` に加えて **`eyelash_thickness`（太さ 0.1/0.15mm 等）**、**`eyelash_length`（長さ mm）**、`eyelash_design`（デザイン：ナチュラル/キュート等）
- EyeRec は左右別で記録している。**我々は Phase1 では左右共通で持ち、要望が出たら分離**を推奨（過剰設計の回避）

### ヘア
- `hair_shampoo_used` / `hair_styling_agent`（使用薬剤・スタイリング剤）※店販につながる
- `hair_color_formula` は既存で正しい

### リラク
- `relax_symptom`（主訴：肩こり/腰痛等）、`relax_contraindication`（禁忌事項：妊娠中・持病等）
- **禁忌は `allergy_flag` と同格の事故防止項目。強調表示すべき。**

## 4. 「刺さる」細かい工夫（競合から抽出）

1. **写真に手書きで書き込める**（複数競合が実装）。ネイル・リラクで需要が強い。
2. **前回カルテのコピーで新規作成**。リピーターの入力が数秒で終わる＝現場の継続率を決める。
3. **アレルギー/禁忌は開いた瞬間に赤で出す**。紙カルテ事故の代替価値そのもの。
4. **データ持ち出し自由（CSVエクスポート）**を明言する。乗り換え不安を消す最強の一言。
5. 顧客の**嗜好メモ（ドラマ・映画・食べ物）**は競合にほぼ無い。**我々の差別化ポイント。**
   → 「前回の続きの会話ができる」＝リピート率に直結する唯一無二の売り。

## 5. リチャードの結論

**現仕様は方向として正しい。追加すべきは「金額・メニュー名・次回来店目安」の3つ。**
差別化の核は **嗜好メモ × 業種別の技術記録** の2枚看板。ここを厚くすべき。

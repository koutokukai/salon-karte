# 【メガネ】将来の連携候補機能リスト

提出日：2026-09-04 ／ 提出先：ゲンさん

> **前提：予約管理はノータッチ。** サロンボードの領域には一切踏み込まない。
> 以下はすべて「**カルテという資産があるから作れるもの**」に限定している。

## Tier 1 — カルテ完成直後に着手できる（次フェーズ）

### ① 来店リマインド LINE 配信 ★本命
- Cloudflare Workers（cron）+ LINE Messaging API
- カルテの `visit_date` と業種別の標準周期（ネイル3〜4週／マツエク3週／ヘア6〜8週／リラク2週）から
  「そろそろですね」を自動送信。**リピート率アップという目的に最も直線的に効く。**
- 実装コストは小。カルテが埋まっていれば送信対象は自動で決まる。

### ② 誕生日・記念日メッセージ
- `customers.birthday` が既にある。**追加テーブル不要で価値が出る最安の機能。**
- 嗜好メモ（好きな食べ物）と組み合わせた文面提案までいけると他社が真似できない。

### ③ カルテのPDF/CSVエクスポート
- 「データはいつでも持ち出せます」は競合が訴求している安心材料。
- **営業のクロージング材料**になるので、機能価値より営業価値で推す。

## Tier 2 — 半年以内（横展開の起点）

### ④ 施術ビフォーアフター集約 → 集客素材化
- 個人スマホに散らばった写真がカルテに集まる。これを**タグ付きギャラリー**として再利用。
- Instagram 投稿用の書き出し（正方形トリミング＋店名透かし）まで用意すれば、
  「カルテを書くほど投稿ネタが貯まる」構造になる。**入力継続の動機付けとして強い。**

### ⑤ 事前カウンセリングフォーム
- 来店前に LINE でフォーム回答 → `customers` と初回カルテに自動流し込み。
- 当日の時短＝**回転率**に効くので、経営者に対する説明が最も簡単な機能。

### ⑥ 店販在庫管理
- ネイルチップ、シャンプー、グルー、オイル等。
- カルテの「使用薬剤」から消費量を推定できるのが我々だけの強み。
- ただし**単体では地味**。④⑤の後で良い。

## Tier 3 — 検討のみ（現時点では推さない）

### ⑦ スタッフ別の指名・売上分析
- `staff_name` が既にある。集計するだけで出せるが、**店舗規模が大きい客向け**。
  我々の当面のターゲット（個人〜数名店）には刺さりにくい。

### ⑧ 顧客向けマイページ（顧客側から履歴が見える）
- チャット機能が入ると自然な発展先。ただし**個人情報の取り扱い責任が跳ね上がる**。
  ゲンさんの判断を仰ぎたい。急がない。

### ⑨ 他業種への横展開（まつげパーマ専門、脱毛、エステ、ペットサロン）
- **スキーマを1テーブルに統一した設計の最大の見返り。**
  業種を1つ足す＝カラム追加＋子コンポーネント1個。**1日で新業種に営業をかけられる。**
- ひろぽんの営業ストックと直結する話なので、ゲンさん経由で共有したい。

## メガネからゲンさんへ

Tier 1 の ①②③ は**カルテ本体の実装が終われば数日で足せる**。
特に①は「なぜカルテを入力するのか」への答えそのものなので、
**Phase 2 の目玉として先に決めておいた方が営業トークが強くなる**と考える。

なお、①は「リマインド送信」であって予約枠の管理ではない。**予約管理には踏み込まない。**
